# Falling Sand — 粉遊びサンドボックス

砂・水・火・油・溶岩・酸・植物などがセルオートマトンで相互作用する箱庭。
さらに**意思を持って動く「虫」**と、添付画像から追加した**火を吐く「ドラゴン」**を
乗せている。どちらも物理的には1セルだが、見た目は大きな画像として重ね描きする。
着火・結露・溶解をWebAudioの短い音へ変えるソニフィケーションと、90度単位の
回転重力、描いて作る風・引力の力場も備える。
決定的PRNGとリングバッファにより、過去へ巻き戻して別の素材を置く分岐と
保存履歴の再生もブラウザ内だけで行える。
物理・化学はCPUで解き（純粋ロジックとして単体テスト可能）、描画はWebGL2で
発光（グロー）を足して見せる。WebGL2非対応環境では自動でCanvas2Dへ退避する。

外部ライブラリ不使用のプレーンなESモジュール構成で、ビルド不要。
静的サイトとしてそのまま配信できる（Cloudflare Pages等）。

## Context（役割・責任範囲・やらないこと）

- **役割**: ブラウザ上で動く粉遊びシミュレーションのデモ。
- **責任範囲**: グリッド状のセル自動機（重力・流動・上昇・反応）と、その描画・入力。
- **やらないこと**: 保存/共有、サーバ通信、GPU上でのシミュレーション（物理はCPU）。
  リアルな流体力学ではなく「それっぽく面白い」挙動を狙う。

## 素材と主な相互作用

- **砂**: 落下して斜めに崩れ、安息角で積もる。水より重いので水中へ沈む。
- **水**: 落下し、行き場がなければ横へ広がる。油より重い（油は上に浮く）。
- **油**: 水より軽く上へ浮く。可燃。
- **火**: 上昇しながら隣の可燃物（油・木・植物）へ着火。寿命で煙へ。水に触れると消え、水は蒸気に。
- **木 / 植物**: 静止する固体。可燃。植物は隣接する水へ成長して広がる。
- **溶岩**: 重い液体。可燃物へ着火し、水に触れると固化して壁（石）になる。
- **酸**: 液体。隣接する砂・木・植物を溶かし、反応すると自身も消費される。
- **煙 / 蒸気**: 上昇して拡散し、寿命で消える（蒸気は稀に水へ結露）。
- **壁**: 動かない・燃えない・溶けない仕切り。
- **虫（生きもの）**: 意思を持って動く個体（画面上はドット絵の甲虫で表示）。植物を
  食べてエネルギーを回復し、余れば繁殖する。火/溶岩を感知して逃げ、隣接すると焼死
  （煙化）、水に囲まれると溺死、酸で溶ける。砂は掘って進む。エネルギーが尽きると餓死する。
- **ドラゴン**: 添付画像の黒背景を透明化して大きく表示する個体。ゆっくり地上を歩き、
  進んだ方向へ顔を向けて火を吐く。火炎は壁で止まり、水を蒸気に変える。火・溶岩では燃えない。

密度（`materials.js` の `density`）で「沈む/浮く/押しのける」を統一的に決めている。
虫は密度 `Infinity`（他素材から押し流されない）で、移動は虫専用ロジックが担う。
グリッドの外周は暗黙の固い壁として扱う（外へは出られない）。

### 簡易生態系（オリジナル要素）

`水際で植物が育つ → 虫が食べて増える → 増えすぎると餌が枯れる → 餓死で個体数が
減る → 植物が再生する` というフィードバックが自然に生まれる。虫の生態バランス
（初期/上限エネルギー・採餌回復・繁殖条件・感知範囲・掘削確率など）は
`src/config.js` の `creatures` に集約している。

## Usage（使い方・注意点）

### 動かす

ビルド不要。ローカルで静的配信して開く（ESモジュールのため `file://` では動かない）:

```bash
cd falling-sand
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

### 操作

- 下部パレットで素材を選び、画面をなぞって描く（マウス/タッチ対応）。
- 「ドラゴン」は画面を1回押すごとに1体出現する（ドラッグでは増えない）。
- 「ドラゴン」サイズスライダーで、表示中と今後置くドラゴンを4〜24セルの範囲で
  即座に拡大・縮小できる。物理上の当たり判定は1セルのまま変わらない。
- 「重力」ボタンで全体重力を時計回りに90度ずつ回す。粉体・液体・気体・虫・
  ドラゴンの落下や上昇方向が変わり、ドラゴンの表示も重力面へ向く。
- 「風」を選び、流したい向きへドラッグすると紫の風を描く。「引力」はタップした
  点へ動的素材を引き寄せる。「場消し」「力場消去」で風・引力だけを消せる。
  壁・木・植物などの静的素材は力場で動かない。
- 「音 OFF」を押して有効にすると、着火は高音、結露は滴音、溶解は低いノイズになる。
  ブラウザの自動再生制限に合わせ、音は毎回OFFで開始する。
- 時間スライダーを左へ動かすと、その時点へ戻って自動停止する。そこで素材・風・
  引力・重力を変更するか「再生」を押すと、以降の履歴を破棄して新しい未来へ分岐する。
- 「履歴再生」は現在位置から保存済みの状態を順に再生する。最新位置から押した場合は
  最古の履歴へ戻ってから再生する。
- 「筆」スライダーで太さを変更。
- `Space`（または「停止」ボタン）で一時停止、`C`（または「消去」）で全消去。

### テスト

```bash
cd falling-sand
node --test
```

物理ルール（落下・密度分離・着火・消火・成長・溶解・ドラゴンの向きと火炎）、
回転重力・力場、反応イベント・発音間引き、決定的な巻き戻しと分岐、
画像透明化・左右反転描画・筆・解像度算出を検証する。

### チューニング

見た目・挙動の調整は原則 `src/config.js` だけで完結する（反応確率・寿命・
虫・ドラゴンの挙動 `creatures`・力場 `forces`・音響 `sonification`・解像度・
時間履歴 `timeline`・ドラゴン表示範囲 `render`・筆サイズ・グロー強度など）。新しい素材は
`src/materials.js` の表へ1要素追加し、必要なら `simulation.js` に挙動分岐を足す。
